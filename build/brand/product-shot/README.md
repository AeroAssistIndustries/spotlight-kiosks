# Kiosk product shot

`capture.cjs` screenshots the live Lexen kiosk screen (kiosk-app, 1080×1920) with the ad slot set to "Your business" and a QR code to citypulsekiosks.com. `compose.html` places it on a CityPulse kiosk in front of the Lexen lounge photo (`assets/lexen/lounge.jpg`) with the ad callout. Render compose.html at 1600×1200 and save as `assets/kiosk-lexen.jpg` (and 900×675 `-sm`). The same files are also written as `kiosk-lobby*.jpg`, which older page content still uses.
