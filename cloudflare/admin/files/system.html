Everything a guest, you or an advertiser does passes through one Cloudflare worker, which keeps all content and numbers in one database.

The kiosk also pulls weather straight from weather.gov. Code lives on GitHub; every change rebuilds the kiosk screen, the website and the worker automatically.

What happens, step by step

A guest uses the kiosk

  1. The lobby screen opens the kiosk page from GitHub Pages.
  2. It loads the latest content from the worker and keeps a copy, so it still works if the internet drops.
  3. Weather comes from weather.gov; questions go to the worker, which asks Workers AI.
  4. Once a minute the kiosk sends its counts to the worker, which saves them in the database.

A guest scans a QR code

  1. The phone opens a short CityPulse link on the worker.
  2. The worker counts the scan for that business or place.
  3. It forwards the phone to Google Maps, the advertiser's website or the phone guide.

You change something

  1. Edit hotel info, places, answers or ads here.
  2. Publish. The worker saves a new version, so any version can be restored.
  3. Every kiosk checks in every 2 minutes and switches when nobody is using it.

An advertiser orders

  1. They complete the website checkout and sign the Advertiser Agreement.
  2. FormSubmit emails the order and their files to Gmail; Stripe takes payment once connected.
  3. You add the ad here, publish, and send them their live report link.
