This dashboard has no username: one staff password opens it, on any laptop or phone. Bookmark spotlight-kiosks.sarvesh-bb0.workers.dev/admin.

Signing in and publishing

  1. Open the dashboard link, type the staff password and click Sign in. Sessions last 12 hours.
  2. Make changes in any section. A bar appears at the bottom: you have unpublished changes.
  3. Click Publish to kiosks. Every kiosk switches to the new version within about 2 minutes, when no guest is using it.
  4. To make it happen at once, open Kiosks and click Restart.
  5. Click Sign out in the sidebar when you are done on a shared computer.

Press Ctrl+K (⌘K on a Mac) anywhere to jump to a page, place, advertiser or action.

Password and recovery codes

Open Password & security at the bottom of the sidebar.

  • Change password: type the current one and the new one (at least 10 characters). Everyone else is signed out.
  • Recovery codes: create a set of 8 and print them or keep them in a password manager. Each code resets the password once.

Forgot the password

  1. On the sign-in screen, click Forgot password?
  2. Enter one of your recovery codes and a new password, then click Reset and sign in.

No codes left? The account owner resets it in Cloudflare: Workers & Pages → spotlight-kiosks → Settings → Variables and Secrets → edit ADMIN_PASSWORD → Rotate → Deploy. That password then signs in, and the old password and codes stop working.

Changing the password in the dashboard keeps advertisers' report links working. Changing ADMIN_PASSWORD in Cloudflare turns them off, so send new links from Ads → Advertiser report.

Adding a new kiosk

On the new screen, open the kiosk link once with a name on the end, for example …/kiosk-app/?kiosk=lobby-2. It appears under Kiosks within 2 minutes and keeps that name.
