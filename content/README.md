# Kiosk content folder

Pictures and videos in this folder play on the CityPulse demo kiosk, in name order.

To add content: on GitHub, open this folder, choose **Add file → Upload files**, drop in your pictures (JPG, PNG, WebP) or videos (MP4, WebM), then **Commit changes**. The kiosk picks them up within 10 minutes.

- Name files so they sort in the order you want, for example `01-welcome.jpg`, `02-venues.mp4`.
- Keep videos small (under 25 MB each) so they load on the kiosk.
- Anything in this folder is public.
